Design a professional web dashboard called "Atgeir HR Screening Dashboard"
following Atgeir Solutions brand guidelines exactly.

BRAND GUIDELINES:
  Primary Blue  : #1D194B
  Accent Orange : #F07C2D
  Off White     : #FCFCFD
  Primary Font  : Poppins (headings, bold statements, weights 600-800)
  Secondary Font: Inter (body text, labels, UI text, weights 400-500)
  Tone          : Modern, friendly, confident, clean, professional

LAYOUT:
  Fixed left sidebar (240px wide) + main content area
  Sidebar background: #1D194B
  Main background: #FCFCFD

SIDEBAR:
  Top: Atgeir logo mark (orange square with "A" + "Atgeir" in Poppins bold)
  Navigation items with icons:
    - All Jobs
    - Screening Results (active state highlighted with orange accent)
    - Candidates
    - Analytics
    - Settings
  Active nav item: subtle orange tint background, orange icon
  Bottom: User avatar + name + role
  Subtle orange radial glow effect in top-right corner of sidebar

TOPBAR (sticky, 60px height):
  Frosted glass effect (white with blur backdrop)
  Left: Breadcrumb navigation
  Right: Export button + Run Pipeline button (orange, Poppins font)

Candidate cards grid (2 columns, 480px min width):

  CARD HEADER (padding 18px 20px):

GLOBAL DESIGN DETAILS:
  Border radius: 12px cards, 8px chips/buttons, 20px pills
  Shadows: 0 4px 16px rgba(29,25,75,0.08)
  Borders: 1px solid #e9ecef on cards
  Spacing: 32px page padding, 16px card gaps, 20px card padding
  Animations: Subtle hover lift (translateY -2px) on cards
  All numbers in Poppins font
  All labels/body in Inter font
  Orange (#F07C2D) used only for: CTAs, active states, rank labels, accent glow
  Dark blue (#1D194B) used for: sidebar, headings, primary buttons, score values
